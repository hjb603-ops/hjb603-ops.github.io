About Me

I’m particularly interested in web development and enjoy building things that are both functional and well presented.

My goal is to keep improving and eventually build software that is practical and useful.

It is not just a final product, but also a record of how my work has developed over time.

Reflection

This section shows how the portfolio links to wider areas of Computer Science.

Computer Architecture

Even though this is a static website, it still depends on real computing hardware. When a user loads the site, it is handled by servers using processors, memory, and storage systems.

This helped me understand that even simple applications rely on more complex systems behind the scenes. It also links to computer architecture topics such as how data is processed and how systems handle requests efficiently.

Databases

This portfolio is not fully database-driven, but a lot of real-world applications are. Studying databases helped me understand how data should be structured, stored, and retrieved properly.

This is useful when thinking about future projects, such as budgeting tools or tracking systems, where data organisation and relationships are important for the system to work effectively.

Web Development

Building this portfolio helped me understand how design, structure, and usability all work together. I realised that small changes, such as spacing and consistency, can significantly improve how professional a website looks.

This project also helped me apply theory in a practical way, which made the learning process more effective.

What I Have Improved

This section summarises how my website has developed over time.

At the start, my website was quite basic and mainly focused on structure. As I continued developing it, I made several improvements to both design and usability.

For example, I improved the layout by adding clearer sections, better spacing, and more consistent styling. This made the site easier to navigate and more visually organised.

I also expanded the content across different sections. Instead of keeping descriptions short, I added more detail to explain what I built, what tools were used, and what I learned from each part of the process.

Overall, these changes made the portfolio feel more complete and more suitable for academic evaluation.
